# 修改现有 PCL 的下载恢复补丁

第三方实验补丁，非官方工具。基于 PCL 公开源码，原作者龙腾猫跃，赞助链接：https://meloong.com/afd/a/LTCat 。许可见 LICENCE。dnlib 使用 MIT 许可，随附 dnlib-LICENSE.txt。

## 怎么用

1. 完整解压补丁 ZIP，保留所有文件。Windows 已能运行 PCL 的机器无需额外安装 .NET SDK。
2. 完全退出要修改的 PCL。
3. 双击 Run.cmd，在弹出的文件选择框中选中你原来使用的 PCL.exe。
4. 显示“下载功能补丁已应用”后，直接运行原来的 PCL.exe，进入“下载”。

脚本会先检查程序集版本号为 2.99.0.0，再匹配目标方法及所需代码引用，生成修改版并检查改动只涉及指定的五个方法，然后在同一目录原子替换文件并生成 .pcl-backup-时间-随机值.bak 原始备份。请保留备份。补丁包无需放进游戏目录，不会移动游戏文件。运行时仅为本次脚本进程指定执行策略，不修改系统执行策略。

## 支持的版本

支持程序集版本号为 2.99.0.0、且所需方法结构兼容的 PCL。没有原 EXE 固定哈希白名单，同版本文件哈希不同不会因此被拒绝。其他版本、无法解析的程序、缺少目标方法或所需引用的构建会停止，原始 EXE 不会被替换。不能保证任意混淆或第三方大幅修改过的 2.99.0.0 都兼容。

内部仍会校验补丁包自己的方法体来源文件，以及检查生成补丁期间原文件是否发生变化；这些都不会要求用户的 EXE 匹配预设哈希。脚本不会下载或替换成另一个启动器发行版。

## 还原

在补丁目录打开 PowerShell：

```powershell
.\Restore-PCL.ps1 -Path '你的启动器完整路径.exe' -Restore
```

或用 Run.cmd 同样传入参数。只有一个原始备份时自动选择；多个备份时加上 `-Backup '备份完整路径.bak'`。还原操作也会保留还原前的 EXE，不删除原始备份。还原已测试，恢复后的 SHA-256 与原始文件一致。

## 补丁实际改什么

从恢复下载限制的公开源码构建中，导入五个方法体，并将所有类型、方法、字段引用重新映射到你的原始 EXE：

- ModModpack.ModpackInstall()：恢复导入对话框。
- ModModpack.ModpackInstall(String, String, String)：恢复整合包类型分派和安装。
- PageDownloadInstall.LoaderInit()：恢复 MC 版本列表。
- PageDownloadModify.LoadInstanceFinished(...)：恢复版本修改页的 MC 选项。
- PageDownloadResourceDetail.InitializeStackResourceVersions(...)：恢复整合包版本的安装按钮。

它不是把名为 RestrictMcDownload 的变量从 True 改成 False；编译期常量已经导致部分代码从官方二进制中被移除，必须恢复对应方法体。restore-methods.dat 是从已公开的恢复版源码编译出的程序集，只作为方法体来源，不会被运行，也不包含官方私有 Client ID/API Key。

原 EXE 的其他方法、内嵌资源和字段常量经过程序比对保持不变。原登录和更新代码没有被替换，但本轮没有重新完成微软登录测试，不保证所有在线功能。官方更新可能覆盖补丁；补丁不屏蔽更新或强制更新逻辑。

## 验证范围

已经测试：原有 2.99.0.0、附加数据后整文件哈希不同但程序集结构相同的 2.99.0.0，均能打补丁；后者还原后字节完全一致。也已验证重复打补丁、自动备份、审计、替换、还原及拒绝 2.10.3.0。实际安装结果另见 verification-result.txt。

UI 验证时使用了额外取消单例检查的测试副本，以避免干扰已经打开的官方 PCL；这个测试性修改没有包含在给用户的补丁中。

未覆盖所有游戏版本、所有加载器组合、完整 CurseForge/Modrinth 整合包安装、新登录和未来 PCL 更新。脚本不读取账户配置，也不上传任何文件；它只读取你选择的 EXE、方法体来源文件及备份。

## 分享给别人

把整个补丁 ZIP 与完整补丁源码 ZIP 一起发给对方，不要只发 PS1，也不要把自己的登录配置发给别人。完整源码包包含构建脚本、方法恢复/审计代码、公开方法体来源的修改源码及许可。
